# 🚀 Challenge – Productivity Management Platform

**Challenge** is a productivity platform designed to help users stay focused, build consistency, and achieve their personal goals. It brings daily challenges, long-term milestones, and essential productivity tools together in one place.

🌐 **Live Demo:** [thechallengeapp.netlify.app](https://thechallengeapp.netlify.app/)

## ✨ Features

- **Challenges:** Create and manage daily challenges with deadlines to build consistency and accountability.
- **Milestones:** Set long-term goals, track progress, and work towards meaningful achievements.
- **Bucket List:** Organize personal goals, dreams, and experiences you want to accomplish.
- **Notes:** Capture ideas, thoughts, and important information in an integrated notes editor.
- **Stopwatch:** Track focused work sessions and monitor time spent on activities.
- **Reward Vault:** An achievement-based reward system designed to motivate users and encourage productivity.

## 🛠️ Tech Stack

- **Frontend:** React.js, TypeScript
- **Styling:** Tailwind CSS
- **Data Persistence:** LocalStorage
- **Deployment:** Netlify

## 🎯 Our Vision

Challenge aims to make productivity more engaging by combining goal management, time tracking, and personal achievements into a single platform.

Whether you're working towards daily goals or pursuing long-term ambitions, Challenge helps you stay organized, focused, and consistent.
